# 📦 StockFlow — Inventory Management System

**StockFlow** is a web-based inventory management system designed to help small businesses organize products, monitor stock levels, manage categories, and visualize inventory information through a simple and intuitive dashboard.

The project is being developed as a Full Stack application, with an emphasis on backend development, business logic, and practical software engineering.

> 🚧 **Project status: In Development**

---

## 🎯 Project Goals

The main goal of StockFlow is to build a functional inventory management application that simulates a real-world business environment.

The system aims to provide:

- Product registration and management.
- Inventory quantity monitoring.
- Product categorization.
- Stock level indicators.
- Product search and filtering.
- Dashboard with inventory statistics.
- Data persistence.
- REST API integration between frontend and backend.

---

## 🏗️ Planned Architecture

The application will follow a frontend/backend architecture.

```text
StockFlow/
│
├── frontend/
│   ├── index.html
│   ├── styles.css
│   └── script.js
│
├── backend/
│   └── Spring Boot application
│
└── README.md
```

The frontend will handle the user interface and interactions, while the backend will manage business rules, data processing, and communication with the database.

The frontend and backend will communicate through HTTP requests using a REST API, exchanging data in JSON format.
